## How it works

Pure Python 3.13 stdlib — no dependencies, no network. Generates a 1024×1024 PNG with six news category cards (global, tech, energy, policy, economy, climate) using only `struct`, `zlib`, and `os`.

## Run

```
python3 main.py
```

Entry at `/output/entry.png`.
